1. Web — caliper-foundry-web (PWA at foundry.caliper.dev)

Leptos + WASM build of the Caliper engine. WebGPU acceleration when available. No telemetry, no third-party scripts.

Notes. Side-by-side preview, parameter pills, hardware-aware "Compute on" selector (CPU / WebGPU / Cloud). The Cabinet strip at the bottom holds the user's last 20 jobs in browser IndexedDB. Strict CSP script-src 'self' 'wasm-unsafe-eval'; no third-party scripts, no analytics. The site at foundry.caliper.dev is the same WASM bundle a user can download and host locally.

5. Architecture at a glance

One Rust core, four shells. The protocol crate is the contract; adding a new shell never touches the engine.
